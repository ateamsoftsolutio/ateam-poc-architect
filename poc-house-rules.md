# POC house rules

Copy this file into your project folder as `poc-house-rules.md` and change the values to suit your organisation. The POC skills read it at the start of every run. Delete a line to fall back to the plugin's default for that setting.

- **Approver title:** Product Owner
- **Requester title:** account owner
- **Cost ceiling:** AI running cost within 10% of what the customer pays; amber up to 15%
- **Currencies for cost figures:** USD, plus the user's local currency if they name one (state the exchange rate used and its date)
- **Front-end default:** The project's existing front end; if there is none, a widely used framework such as React
- **Back-end default:** The project's existing back end; if there is none, a widely used option such as Node.js or Python
- **Format for the handover pack and brief when no Claude Doc tool is available:** a Markdown file in the project folder
- **Countries and sectors for compliance flags:** (list them, for example "UAE and Saudi Arabia, healthcare")
- **Mid-build demo audience:** the account owner and the Product Owner
- **Approved AI providers:** Anthropic (Claude) and OpenAI; others only when the customer requires them
- **Anything else Claude must always follow:** (add your own rules here)
